# meinklett.ch Prototyp

Passwortgeschützter Entwurf. Der Inhalt in `docs/index.html` ist mit
AES-256-GCM verschlüsselt, der Schlüssel entsteht per PBKDF2 aus einer
Passphrase. Ohne Passwort ist nichts zu sehen.

Dieses Repository enthält bewusst nur die verschlüsselte Datei, damit
GitHub Pages sie ausliefern kann. Die Quelldateien liegen in einem
privaten Repository.

Klett und Balmer AG – interner Entwurf.
